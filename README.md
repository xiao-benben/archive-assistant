# 归档助手

BEN 的 Windows 本地智能文件管理应用。用户文件固定保存在 `D:\自动归档`；数据库、设置、日志和索引保存在 Windows 应用数据目录。

## 已实现

- 任意层级工作区和子分区，新建、重命名、导入、移动、复制、批量处理与全文搜索
- SHA-256 完全重复检测，以及最新版、历史版、同时间冲突版命名
- 删除进入 Windows 回收站；路径穿越、符号链接和目录连接防护
- 快捷引用式收藏、自定义收藏分区、失效引用提示
- 每日计划、优先级、重复规则、完成记录、电脑通知、托盘与开机启动
- 本地中英文 OCR，支持常见图片与扫描 PDF，按文件指纹缓存并进入搜索索引
- 大模型 API 设置与凭据管理器密钥存储
- WPS、合规微信通知和局域网手机端的接口、数据库结构与设置入口

> WPS、微信和手机端在首版仅预留，不会自行开放端口或上传文件。大模型仅保存配置，不会未经确认发送文件。

## 开发与构建

环境要求：Node.js 20+、Rust stable、Visual Studio 2022 C++ Build Tools、WebView2。

```powershell
npm install
npm run tauri dev
npm run tauri build
```

`npm install` 后会把离线 OCR 运行文件复制到 `public/ocr`。正式安装包位于 `src-tauri/target/release/bundle/nsis`。

## 数据安全

- 应用源码目录 `D:\自动归档\归档助手-app` 被明确排除，不会显示为工作区。
- 删除命令使用 Windows 回收站，不执行静默永久删除。
- OCR 结果只写入索引，不改动原图片或 PDF。
- API 密钥使用 Windows 凭据管理器，不写入数据库或日志。
- 手机访问默认关闭，首版未启动任何网络监听服务。
